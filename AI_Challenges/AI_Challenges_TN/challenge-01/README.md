# Challenge 01 — Insurance Plan Comparison Page

**Live URL:** https://insurtech-challenge-01.vercel.app

## What it does

Side-by-side comparison table for insurance plans — features, premiums, coverage limits, and inclusions across multiple plan tiers. Responsive layout that stacks on mobile.

## Stack

React + TypeScript + Vite · Tailwind CSS

## Local dev

```bash
npm install
npm run dev
# http://localhost:5173
```
