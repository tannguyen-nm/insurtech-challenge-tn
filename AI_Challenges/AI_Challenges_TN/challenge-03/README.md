# Challenge 03 — Claim Notification Email Templates

**Live URL:** https://insurtech-challenge-03.vercel.app

## What it does

Responsive HTML email templates for claim lifecycle notifications. Includes a live preview tool to view all templates at desktop and mobile widths.

## Templates

| Template | Trigger |
|---|---|
| `claim_submitted` | Member submits a new claim |
| `claim_approved` | Claim approved with payout details |
| `claim_rejected` | Claim rejected with reason |
| `payment_sent` | Payment transferred to member |
| `document_requested` | Additional documents required |

## Stack

Pure HTML/CSS email templates · Inline styles for email client compatibility · Mobile-responsive via media queries

## Local preview

Open `index.html` in a browser, or serve with any static file server:

```bash
npx serve .
```
