# Challenge 12 — Multi-Country Regulatory Rule Engine

**Live URL:** https://insurtech-challenge-12.vercel.app

## What it does

UI for managing and testing insurance regulatory rules across countries. Three tabs:

| Tab | Description |
|---|---|
| Validate | Test a claim against the active ruleset; see pass/fail per rule |
| Rules | Browse, enable/disable, and edit individual rules per country |
| Diff | Compare rulesets between two countries side by side |

## Stack

React + TypeScript + Vite · Tailwind CSS

## Local dev

```bash
npm install
npm run dev
# http://localhost:5173
```
