# Challenge 04 — Insurance Glossary Search App

**Live URL:** https://insurtech-challenge-04.vercel.app

## What it does

Searchable glossary of insurance terms with category filtering. Instant search with keyboard navigation, term definitions, and related-term linking.

## Stack

React + TypeScript + Vite · Tailwind CSS

## Local dev

```bash
npm install
npm run dev
# http://localhost:5173
```
