# Challenge 05 — Policy Summary Generator

**Live URL:** https://challenge-05.vercel.app

## What it does

Generates a human-readable policy summary from structured policy data. Renders coverage limits, exclusions, deductibles, and premiums as a clean plain-language summary card.

## Stack

React + TypeScript + Vite · Tailwind CSS

## Local dev

```bash
npm install
npm run dev
# http://localhost:5173
```
