# Challenge 09 — Claims Analytics Dashboard

**Live URL:** https://insurtech-challenge-09.vercel.app

## What it does

Interactive analytics dashboard for claims data. Loads a CSV of claims, parses it client-side, and renders KPI cards (total claims, approval rate, average payout) plus a filterable data table with charts.

## Stack

React + TypeScript + Vite · PapaParse · Recharts · Tailwind CSS

## Local dev

```bash
npm install
npm run dev
# http://localhost:5173
```
