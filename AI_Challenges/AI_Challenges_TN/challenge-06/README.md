# Challenge 06 — Policy Benefits Calculator

**Live URL:** https://insurtech-challenge-06.vercel.app

## What it does

Calculates reimbursement for medical expenses against a policy. Shows per-expense breakdown (covered amount, deductible applied, co-pay) and running totals.

## Stack

React + TypeScript + Vite · Tailwind CSS

## Local dev

```bash
npm install
npm run dev
# http://localhost:5173
```
